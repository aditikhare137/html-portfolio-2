# HTML Birthday Invitation Page

A beginner front-end exercise that presents a birthday invitation using basic HTML.

## Included Content

- Birthday invitation heading and date
- A list of suggested items to bring
- Image and location-related elements

## Tech Stack

- HTML

## Project Structure

- `index.html` — the invitation page and its markup

## Run Locally

1. Clone or download the repository.
2. Open `index.html` in a web browser.

The page includes externally hosted image and map references. Check those URLs and the image markup if any resource does not display as expected.

## What This Project Practises

- HTML document structure
- Headings and lists
- Adding images and external links
- Presenting content in a simple web page

This is a small learning project rather than a complete multi-page portfolio website.
